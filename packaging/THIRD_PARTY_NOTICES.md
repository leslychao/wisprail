# Bundled components

The packaged application contains the original notices and license files from dependency JARs,
the Java runtime and the verified sing-box archive. Retain those files when distributing a package.

- sing-box 1.14.2: GNU GPL v3 or later, [source](https://github.com/SagerNet/sing-box/tree/v1.14.2).
- OpenJDK 21 and OpenJFX 21: GPL v2 with the Classpath Exception; runtime `legal/` and JAR notices.
- Jackson, gRPC Java and JNA: see their bundled `META-INF/LICENSE` and `META-INF/NOTICE` entries.
- Protocol Buffers Java: see its bundled license.

This notice is an inventory, not a replacement for the licenses in the distribution. Before an
external release, supply any corresponding source and notices required by the selected licenses.
